# Privacy and demo data

## Use fictional information only

Fineland is a public, frontend-only demonstration. It has no sign-in and stores the information you enter in browser-local storage on the device and browser you use. The demo is not designed or approved for patient records, protected health information, or other sensitive personal information.

Use invented names, dates, and responses. Do not enter real patient, family, clinician, or clinic information. The interactive example is not a secure clinic record system.

## Browser-local storage

Working demo data stays in the browser's local storage for that browser profile. It is not a shared account or cloud-based record. People with access to the same browser profile may be able to see the data. Clearing site data or browser storage for the demo removes locally saved demo data; the exact browser steps vary.

The public demo is hosted at [fineland-demo.vercel.app](https://fineland-demo.vercel.app/). As with any public website, your browser and network provider may process connection information under their own policies. This page describes the demo's application data behavior, not those providers' practices.

## Safe demo use

- Use fictional records and demonstration responses.
- Avoid entering any information that could identify a real person or clinic.
- Clear the demo's browser storage when you finish if you want to remove your locally saved examples.
- Do not use demo results to make clinical decisions.
