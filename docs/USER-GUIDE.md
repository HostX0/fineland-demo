# User guide

Fineland is a fictional-data demo of an adaptive-behavior interview workflow. You can explore the full path from intake to a printable report in your browser.

## 1. Create a demonstration case

Start a new case and enter fictional identifying details. Add the date of birth and interview date to see chronological age calculated. Use only invented information; do not enter real patient or family details.

The experience distinguishes the reference interview route from a clinic-configured age cap. The clinic cap is a workflow setting and should not be confused with the instrument's reference route.

## 2. Complete the interview

Move through the interview items and choose a response on the 0/1/2 scale, or enter a raw value when the interface offers that option. Follow the on-screen routing and basal/ceiling indicators as you explore. For a quick walkthrough, choose **Fill example responses**, then **Review and calculate** and **Save report**.

The wording shown is demonstration wording, not licensed Vineland-3 item wording. The content exists to make the interaction understandable.

## 3. Review results

The results view demonstrates v-scales and domain results, plus the Adaptive Behavior Composite (ABC), which excludes Motor. It also presents equivalent age and Growth Scale Value (GSV); GSV is not a growth rate.

Explore strengths and pairwise comparisons. Maladaptive behavior results and critical items appear separately from the adaptive domain results.

## 4. Compare follow-ups

Create another fictional assessment for the same demonstration case and use the follow-up comparison to review results side by side. The comparison is a way to explore the interface; it is not evidence of clinical change or a treatment outcome.

## 5. Find, archive, and report

Use search to locate demonstration cases and archive ones you no longer want in the active list. Open report preparation to review the output. Use the browser's print dialog to print or save the report as PDF.

In clinic settings, try the clinic name and default examiner preferences. Add an optional logo to see it in reports, with an optional light watermark.

## Demo data and privacy

The demo has no sign-in and stores its working data in the browser's local storage. Use fictional records only. **Reset demo data** restores the original sample workspace after confirmation. See [Privacy and demo data](PRIVACY.md) for details and cleanup guidance.
