# Assessment and scoring notes

## Instrument context

Fineland demonstrates a workflow based on the **Vineland Adaptive Behavior Scales, Third Edition (Vineland-3), Comprehensive Interview Form**, using the US 2016 reference. Vineland-3 is a Pearson instrument. Fineland is an independent demonstration and is not endorsed by Pearson.

For official public reference material, see Pearson's [Vineland-3 manual appendices B–E](https://www.pearsonassessments.com/content/dam/school/global/clinical/us/assets/vineland-3/vineland-3-manual-appendices-b-e.pdf). This documentation does not reproduce licensed item wording or scoring tables.

## What the demo illustrates

- Item response entry using 0/1/2 or raw values where supported.
- Routing through the interview, including basal and ceiling behavior.
- v-scales, domain results, and the Adaptive Behavior Composite (ABC), which excludes Motor.
- Strengths and pairwise comparisons.
- Maladaptive behavior and critical items as separate result areas.
- Equivalent age and Growth Scale Value (GSV). GSV is not a growth rate.
- Follow-up assessment comparison.
- A clinic-configured age cap, shown distinctly from the reference interview route.

The demo includes numeric reference values supplied for this isolated experience. Its behavior reflects the scoring implementation used here; reproducing an implementation does not establish that it has been clinically validated, independently verified, or approved for operational assessment.

## Intended interpretation

Use the experience to understand the proposed workflow and interface. Do not interpret its sample results as a clinical assessment, diagnosis, or basis for treatment or service decisions. The demo does not replace the official instrument, its administration guidance, qualified professional judgment, or the appropriate permissions and materials needed for real-world use.

## Estimate and expected benefit

The requesting clinician estimated 45–60 minutes or more for manual scoring, table lookup, and report preparation, compared with about 10 minutes or less using the system. These are client-reported estimates, not a measured study result or guaranteed time. The intended benefit is less routine calculation and transcription work and more available clinician time; this does not establish that errors are eliminated or that health outcomes improve.
